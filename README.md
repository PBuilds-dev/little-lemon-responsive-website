# Little Lemon Responsive Website

## Overview

A responsive restaurant website built using HTML and CSS, designed to demonstrate modern layout structure, semantic markup, and mobile-first responsiveness.

The project focuses on UI clarity, visual hierarchy, and consistent design patterns across devices.

---

## Tech Stack

* HTML5
* CSS3 (Flexbox & Grid)
* Responsive Design Principles

---

## Features

* Fully responsive layout (mobile, tablet, desktop)
* Structured navigation system
* Image-driven menu sections
* Semantic HTML architecture
* Optimized layout for performance and readability
